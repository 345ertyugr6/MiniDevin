# MiniDevin Prototype

이 저장소는 복잡한 자동화 기능을 모두 제거하고, 함께 코딩을 시작하기 위한
최소한의 프로토타입만 제공합니다.

## 사용 방법

```bash
python main.py
```

프로그램은 세션 목표를 물은 뒤, 자유롭게 개발 단계를 추가할 수 있는 인터페이스를 제공합니다.
각 단계에는 선택적으로 실행하려는 명령을 기록할 수 있으며, 빈 줄을 입력하면 단계 추가가 끝납니다.
모든 단계를 입력한 후에는 전체 요약이 출력됩니다.

## 구성

- `main.py`: 간단한 CLI 진입점
- `prototype/session.py`: 개발 세션과 단계를 표현하는 데이터 클래스
- `prototype/__init__.py`: 패키지 초기화 파일

함께 기능을 확장하고 싶다면 여기서부터 시작하면 됩니다.
